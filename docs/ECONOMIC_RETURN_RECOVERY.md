# 경제적 수익률 복원: 확인한 사건과 남은 평가 공백

2026-10-11 KST · EXPLORATORY_EXTENSION · **경제적 수익률 수정 0건**

결측은 곧 손실이나 데이터 오류가 아니다. 실제 투자자는 합병 신주·현금채권·비상장 잔존주식을 보유할 수 있고, 100% 넘게 상승한 가격수익률도 가능하다. 이 감사는 기존 규칙으로 형성한 보유경로의 첫 결측 13개 전략-종목 기록을 11개 고유 종목-월로 묶어 각각 조사했다. 원천 종목코드·기업명·원가격·전월가격·시점별 비중·법인코드의 조인 상세는 소유자 분석 환경에만 보관했다. 역사적 ISIN은 미확보이며, 원패널의 시장 구분이 공식 역사적 식별번호 검증을 대신하지 않는다.

앞선 수집은 후보 제목 58개를 찾는 데 그쳤다. 이번에는 그 목록을 검토하고 관련 접수번호 16개의 공식 본문 37개 절을 읽었다. 인증 없는 DART 웹 조회 53회와 해시 캐시를 사용했으며 전수 API 재수집은 반복하지 않았다. [본문 주소·접수번호·SHA256·수집시각](../outputs/final/event_evidence_register.csv)은 공개 증빙이다. 공시의 개인정보와 본문 원파일은 재게시하지 않았다. KRX 「개별종목 시세 추이」를 실제 열었으나 **로그인 또는 회원가입 필요** 안내로 월말 가격 조회가 차단됐다. 인증·유료 접근을 우회하지 않았다.

## 전체 결측·필터와 보유종목의 관계

stock_returns 226,563행의 결측 2,068건은 왼쪽 조인으로 모두 보존했다. 배타적 원자료 필드 분류는 현재 가격 부재 352, 이전 가격/첫 관측 부재 1,054, 100% 초과 필터 659, 기타 원수익률 공백 3건이다. 연구기간 2016-01~2026-04의 결측 339건은 각각 0/124/213/2건이다. 이는 **원수익률 파일에 있는 행**의 분류다. 퇴출로 그 월의 원수익률 행 자체가 사라진 보유종목은 이 339건 안에 포함되지 않을 수 있다. 공시 사건의 경제적 원인을 모두 확정한 분류는 아니다.

659건은 모두 양의 100% 초과 변화다. 이 중 연구기간은 213건이며 결측의 부분집합이다. 659와 2,068, 또는 213과 339를 더하지 않는다. 보유경로에서는 VFS 7건(원가격 부재 4·필터 3), Value 6건(부재 4·필터 2)이다. 두 전략의 중복을 제거한 고유 사건은 11건이다. [원자료 분류](../outputs/final/source_missingness_types.json), [공개 집계](../outputs/final/held_gap_audit_public.csv).

## 작은 비중도 경로를 임의로 이어 붙일 근거가 아니다

최초 중단 월의 미확인 보유비중 합계는 VFS 0.0113~0.3602%, Value 0.0420~0.3432%다. 별도 잠금한 가정은 해당 종목 수익률이 -100/-50/+50/+100%일 때 `미확인 비중 × 가정 수익률`의 기여분만 계산한다. 예를 들어 최대 VFS 노출 0.3602%에는 ±100% 가정에서 ±0.3602%p의 기여분이 대응한다. **실측 월수익률·완전한 포트폴리오 수익률·신뢰구간·상하한이 아니다.** 100% 넘는 상승도 가능하고 확률을 부여하지 않았다. NAV를 연장하거나 결측을 대체하지 않는다.

## 2016~2020년은 API 공백과 공시 부재를 구분한다

기존 연간 응답 캐시를 다시 조사했다. 2015~2018년에는 각 743/752/759/763개 기업·연도 요청의 G가 전부 `013`이었다. 2019년에는 769개 중 정상 응답 2개·미제공 767개였다. 2019년 정상 G 두 응답의 접수번호는 2022/2023년이어서 2020년 형성 신호로 소급할 수 없다. 재무 정상 응답은 같은 연도에 705/706/723/736/741개였다. 이 자체가 과거 공시나 이사 정보가 없다는 뜻은 아니다. [연도별 API 커버리지](../outputs/final/historical_api_coverage.json).

따라서 2019년 사업보고서 한 건의 공식 이사회 본문을 인증 없이 2회 조회하는 대안도 실행했다. 본문 접근은 가능했다. 다만 서술은 사내 3·사외 2명이고 명단은 사내 3·사외 3명이며, 2020년 3월 선임 변동을 함께 기재한다. 회계연도 말과 제출일 현재, 서술·명단의 불일치를 해소하지 않은 자동 숫자 추출은 잘못된 G가 될 수 있다. 이를 새 신호로 투입하지 않았다. [접근·해시·미검증 판정](../outputs/final/historical_body_smoke.json). 원문 직접 수집은 가능한 후속 자료 경로이지만 전 모집단의 일관된 시점·변동 검증을 완료한 패널은 아니다. 이번 결과를 ‘과거 자료 복원 불가능’이나 ‘2016~2020 수집 완료’로 과장하지 않는다.
