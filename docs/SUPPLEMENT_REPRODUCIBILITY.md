# FnGuide 보완 분석: 방법과 재현

이번 보완은 「사외이사 비율은 PBR 기반 종목선별을 보완하는가?」라는 한 질문에 답한다. 원문의 MSCI Governance Score와 독립 연구의 사외이사 비율을 구분하고, 다른 프로젝트의 결과·코드·팩터 추정치를 가져오지 않았다. 원래 가격수익률, 네 셀 집계, 기존 강건성 및 설계 잠금은 변경하지 않았다.

## 원천과 단위

- 사용자가 제공한 월간·연간 CSV는 434,893행이다. `frequency`를 필터링해 월간 420,924행과 연간 13,969행을 구분했다. 종목코드의 `A` 접두어만 제거하고 기존 6자리 식별자와 월 키로 정확히 결합한다. 일부 영숫자 신규 코드는 그대로 보존해 충돌을 피한다. 중복 종목-월은 0건이다.
- 파일의 월 키에는 2027년까지의 빈 미래 행도 있다. 유효 배당 포함 수익률은 2006-01~2026-06에 160,243개이며, 이번 보완에서는 원래 비교기간과 2021-07~2026-04 매칭 단면만 사용했다. 미래 키를 실측 수익률로 취급하거나 기간을 연장하지 않았다.
- `KR_return_cash_dividend_included_pct`는 퍼센트이므로 100으로 나눈다. `KR_price_cash_dividend_included_krw`의 연속 월 비율과 160,243건을 대조했으며 최대 소수 수익률 오차는 8.89e-16 이하였다. 수익률 필드의 내부 산술 검증이며 독립적인 배당 지급·상폐 대가 검증은 아니다.
- 기존 PIT `lag_me`는 천원, 표의 시총은 십억원(`lag_me / 1e6`), `roe`는 소수(`roe × 100` = %)다. 새로운 FnGuide 재무정보는 공시일이 없어 선정·PIT 통제에 사용하지 않았다.
- 팩터·금리 파일은 318행, 2000-01~2026-06의 스키마만 확인했다. 변수명에 적힌 percent와 decimal을 구분했으며 팩터 결과·시장 대용치·회귀에 사용하지 않았다.
- 일간 Excel은 Sheet1의 34행에 날짜, R열에 종목, U열에 항목코드가 있는 넓은 형식이다. 날짜는 2009-12-30~2026-05-26이다. 이름·항목 설명 일부가 깨져 있어 설명 문자열로 조인하지 않고 코드 `S410000700`(수정주가, 원), `S410001600`(수정계수)을 사용했다. 원천 OHLC나 수정계수만으로 경제적 실현 수익률을 역산하지 않았다.

원천 세 파일의 SHA256, 필드 목록, 적용 범위는 [스키마](../outputs/supplement/source_schema.json)와 [일간 요약](../outputs/supplement/daily_audit_summary.json)에 기록했다. 원천·종목별 패널·보유비중·매칭 짝은 로컬 `_workspace/`에만 보존한다. 공개 산출물은 집계다.

## 원래 종목·비중을 고정한 배당 포함 민감도

기존 Python `validate_cell_input`, `validate_panel`, `annual_membership`를 호출해 원래 형성 집단을 가져왔다. 새 TypeScript 계산은 원래 25% 셀 상한, VFS 50:50 배분, Value의 전체 Low 시총 비중과 매월 가격에 의한 비중 변동을 재현한다. 공개 기준과 모든 원래 비교 월의 셀·VFS·Value 가격수익률을 1e-12 허용오차로 대조한다.

저PBR 2021-07~12, 고PBR 2022-07~10, VFS−Value 2021-07~12에서 원래 가격경로의 월초 비중을 동결해 수익률 필드만 대체한다. 매칭 누락 시 누락 수익률을 0으로 채우지 않는다. 매칭된 보유 종목의 원래 비중 합으로 재정규화한 **조건부 월평균**과, 바로 그 종목·비중으로 계산한 원래 가격수익률을 나란히 제시한다. 서로 다른 두 집단은 각자 재정규화하므로 이것은 완전한 포트폴리오 spread가 아니다.

전체 보유 종목이 매칭되는 월만 `total_fixed_weights_complete`를 기록하고, 결측이 한 번이라도 있으면 별도의 총수익률 자연 변동 경로는 연간 형성까지 중단한다. 이번에는 모든 비교에 일부 누락이 있어 전체 기간의 총수익률 spread·누적 수익률은 NA다. 부분 평균을 누적 NAV로 연결하지 않는다. 원래 가격 비중을 고정한 민감도는 총수익률로 비중이 변하는 자기금융 전략과도 구분된다.

[월별 수익률·비중 커버리지](../outputs/supplement/dividend_monthly.csv) · [기간 요약](../outputs/supplement/dividend_summary.csv). 표의 최저 커버리지는 비교하는 두 집단×월의 최저 원래 비중 비율이며, 기업-월 매칭 수는 두 집단 합계다.

## 한 가지 탐색적 매칭

[보완 규칙](../config/supplement_plan.json)은 보완 수익률을 계산하기 전에 작성했다. 기존 결과를 알고 설계했으므로 독립 사전등록이 아니다. 같은 형성연도와 원래 PBR 집단 내에서 다음 세 한도를 모두 만족한 Good/Bad만 후보로 삼았다.

- `|log(ME_good / ME_bad)| ≤ log(2)`
- `|ROE_good − ROE_bad| ≤ 0.05` (5%p)
- `|log(PBR_good / PBR_bad)| ≤ log(1.5)`

세 차이를 각 한도로 나눈 값의 제곱 합을 거리로 사용한다. 모든 허용 후보를 거리 오름차순으로 정렬하고, 동률은 고정된 종목 식별자 순서로 결정해 중복 없는 1:1 짝을 고른다. 전역 최적화가 아닌 결정적 탐욕 매칭이다. 수익률과 미래 관측 가능성은 짝 선택에 넣지 않는다. ROE 결측은 비교 전후 공통 가용성 기준에서 제외한다. 결과를 본 뒤 한도·표본기간을 바꾸지 않았다.

매칭 전은 해당 PIT ROE 가용 기업에서 Good/Bad의 월별 관측 가격수익률 평균 차이, 매칭 후는 같은 달 두 가격이 모두 관측된 짝의 평균 차이다. 양쪽 모두 같은 58개월을 단순 평균하지만 기업 구성과 관측 선택은 달라진다. 앞의 전체 58개월 단면과도 ROE 가용성 때문에 모집단이 다르다. 절대 표준화 평균차는 같은 형성군·변수의 매칭 전 합동 표준편차를 공통 분모로 사용한다. 매칭 후 분모를 축소해 균형을 다르게 평가하지 않는다.

저PBR 438짝·5,034/5,076 관측 짝-월, 고PBR 331짝·3,816/3,852 관측 짝-월이다. 기업의 반복 형성과 반복 월을 독립 표본으로 세지 않는다. 5개 형성군으로 통계적 유의성·p값·CI·인과효과를 추정하지 않았다. 짝의 양쪽 가격과 배당 포함 필드까지 있는 동일 부분 표본으로 수익률 기준만 대체한 민감도도 제공한다. 결측에 따라 각 월의 구성은 달라지며 이것도 투자 가능한 매칭 전략이 아니다.

## 가격 이상 확인과 미복원

기존 첫 보유 결측 11개 고유 사건의 이전 달·당월의 **전체 시장 마지막 세션**을 기준으로 일간 수정주가·수정계수를 조회했다. 종목별 마지막 가용 가격으로 월말 결측을 대체하지 않았다. 파일에 있는 3건(E05·E06·E08)은 양월 수정주가 비율이 원래 100% 초과 원수익률과 일치하고, 월말 수정계수 변화도 0건이었다. 나머지 8건은 파일의 종목 행이 없었다. 수정계수의 변화 여부만으로 모든 월중 기업행동이나 경제적 대가를 검증할 수 없다.

따라서 필터 해제·기간 연장·경제적 수익률 복원은 0건이다. 이 파일에서 누락됐다는 사실은 해당 기업의 역사적 가격 자체가 존재하지 않는다는 뜻이 아니다. 상폐·합병·현금 지급 및 형성 시 거래 가능성은 기존 감사의 미검증 판정을 유지했다. [사건별 확인](../outputs/supplement/daily_event_audit.csv).

## 실행과 공개 검증

Node 22 이상에서 `npm ci`, `npm run typecheck`, `npx tsx src/harness.ts`, `npm run publish`로 공개 집계의 산술·커버리지·본문·차트·보존 SHA256를 검증하고 README·Pages를 같은 자료에서 생성한다. 원천 없이 CI에서 재현되는 것은 집계 산술과 출판이며 원천 데이터 감사 자체가 아니다.

로컬 원천 재실행은 `npm run analyze`와 `npx tsx src/daily_audit.ts`다. `VFS_FNGUIDE_ROOT`(세 원천 파일 폴더), `VFS_PIT_PANEL`(검증 PIT parquet), `VFS_GAP_DIAGNOSIS`(기존 종목별 결측 감사), `VFS_PYTHON`(기존 Python 분석 환경)을 환경변수로 지정할 수 있다. 기본 경로는 저장소 옆의 제공 자료이며 공개 파일에 절대 개인 경로를 기록하지 않는다. Python 어댑터는 기존 형성·PIT 검사와 직렬화 및 표준 ZIP/XML 추출에 사용하고, 신규 분석·출판·검증 스크립트는 strict TypeScript다.

기존 Python 검증 `python -m pytest -q`, `python -m vfs_research.cli verify-public`도 수행한다. 기존 원천 재구축 모듈은 POSIX `fcntl`을 사용하므로 전체 기존 테스트는 Linux/WSL 및 GitHub Actions에서 수행한다. PDF를 읽거나 생성하는 명령은 실행하지 않는다.
