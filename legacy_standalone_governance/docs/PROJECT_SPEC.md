# 연구 설계

## 질문과 범위

한국 가치 프리미엄 내부에 공시 기반 거버넌스 정보의 증분이 있는가? HML을 관찰한 것과 그 원인을 설명한 것은 다르다. 주 검정은 같은 HighBM 집단 안에서 HighG−LowG 수익률을 비교하고 FF3 통제 후 알파를 추정하는 것이다. 좋은 성과를 사전에 가정하지 않는다.

| 구분 | 사전 지정 |
| --- | --- |
| Primary G | 독립(사외)이사 수 / 이사 수 |
| BM/G 소팅 | 공통 G 커버리지 표본의 BM 중위값, 각 BM 집단 내부 G 중위값 |
| 가중 | 전월 말 시가총액(VW); EW는 민감도 |
| 공개일 규칙 | 실제 공시목록 날짜+1일 → 처음 도달하는 월말 → 이후 달 수익률 |
| 형성 시점 | 수익률 관측월의 직전 월말 |
| 최소 표본 | 셀당 5종목, 회귀 공통 연속 24개월 |
| 회귀 | 월 소수수익률; MKT−RF, SMB, HML; OLS와 HAC 3개월 |
| RF | 롱온리 1회, 자기금융 스프레드 0회 차감 |
| 민감도 | EW/VW, G 30/70% 분리 기준, 시총 상위 5종목 제외 |
| 미확보 통제 | 업종, ROE/수익성, 검증된 시장구분, 실행비용 |

독립(사외)이사 비중은 명목 감독구조의 대리지표로, G의 전체 범위를 포착하지 않는다. 지분집중·자기주식·주총 준수와의 임의 가중 합성은 이번 MVP에서 보류한다. 값 동점으로 셀이 사라지면 전략을 추정하지 않는다. 구성종목 중 수익률 누락이 있으면 생존종목만으로 재가중하지 않는다.

## 실제 실행 경로

2026-10-09 실행은 `Fallback C`: 과거 G 데이터·인증키가 없어 기초 FF3 재구성, 원본 입력 감사, 공시 수집/PIT/통계 검정 코드와 자동 검증을 수행한다. 현재 단면 ESG 점수를 장기 수익률에 소급 적용하지 않는다. 결과 파일은 미추정 이유와 다음 입력을 담는다.

G 이력과 재무공시 공개일 근거가 모두 생기면 동일 표본월에서 제한된 탐색 분석을 수행한다. 24개월은 통계적 우수성의 보증이 아니다. 추정치·불확실성·표본과 잔존 편향을 함께 보고한다. COE·정당화 PBR의 신규 수치는 계산하지 않고 경제적 동기만 참고한다.

## 기존 FF3의 구성 규약 감사

원본 코드 재현(`legacy_compatible`)과 전년 장부자본/현재 6월 ME 기준(`spec_aligned`)을 모두 출력한다. 후자는 실제 재무공시 공개일이 검증된 값이라고 주장하지 않는다. 기초 팩터 시계열은 G 전략의 공시 근거가 아니며 새로운 G 알파와 혼동하지 않는다.

원본 parquet·보고서·코드를 수정하거나 재배포하지 않는다. 고정 커밋을 외부 입력으로 읽고 전후 SHA-256을 비교한다. 기존 연구 보고 숫자, 참고 리서치의 숫자, 새 계산값의 근거를 분리한다.
