# RA 면접에서 설명할 VFS 연구

미래에셋 「멀티플 탈출」의 PBR×거버넌스 전략을 OpenDART 사외이사 비율과 공시 시점에 맞춰 독립 구현했습니다. 실제 원천 증빙 9,186개와 PIT 결합 782기업을 검증하고, VFS 8개월·Value 공통 6개월의 가격 경로를 다시 실행했습니다. 공통기간 VFS와 Value의 누적 가격수익률은 -11.14%와 -13.72%, 월평균 차이는 +0.4325%p였습니다. 표본이 짧아 FF3 알파를 추정하지 않았고, 실제 보유 결측 11건의 공식 본문을 조사해 경제적 수익률을 확정할 수 없는 이유까지 공개했습니다. 연구 기여는 높은 수익률의 발견보다 재현 가능한 규칙·증빙·실패 판정과 해석 범위의 관리에 있습니다.

| 예상 반문 | 답변과 증빙 |
| --- | --- |
| 왜 월 N이 짧습니까? | PIT G·재무 결합은 2021년 이후다. 보유종목 결측부터 연간 경로를 중단하는 사전 가정으로 VFS 8개월·공통 6개월만 연속이다. 13개 보유 기록을 11개 사건으로 묶어 본문을 확인했지만 가격·권리·대가를 함께 검증하지 못했다. [사건별 이유](ECONOMIC_RETURN_RECOVERY.md) |
| MSCI와 같은 전략입니까? | 2×2 규칙은 따라가지만 사외이사 비율은 이사회 한 측면이다. 소유·보상·회계 투명성까지 평가하는 MSCI G를 대체한다고 주장하지 않는다. [차이](ORIGINAL_VS_IMPLEMENTATION.md) |
| +0.43%p가 G 프리미엄입니까? | 기술통계다. PBR 예산·규모·상한 차이도 섞인다. EW spread는 음수이고 G-neutral은 2개월뿐이다. 인과효과나 유의한 알파는 증명하지 못했다. [결론](RESEARCH_CONCLUSION.md) |
| 배당과 상폐는 어떻게 처리했습니까? | 가격수익률만 제시했다. 교환·합병·상폐 본문에서 계약 조건과 일정은 확인해도 실현 대가·월말 평가는 별도다. 결측을 0이나 -100%로 채우지 않았다. [수정 0건](../outputs/final/return_repair_status.csv) |
| 재현성과 보안을 어떻게 확인했습니까? | 공개 CSV 산술 검사와 적법한 로컬 원천 재실행을 분리했다. 원천 해시와 오프라인 재실행을 검증했으며 키·종목별 원천을 GitHub에 올리지 않았다. [실행 가이드](REPRODUCIBILITY.md) |

핵심 구현은 연간 PIT·동점 규칙·형성 상한·보유비중 드리프트·RF 처리·미추정 통계와 경제적 대가의 이중 조정 차단이다. 기존 미국/한국 FF3 원본은 읽기 전용으로 유지했다. 과거 거버넌스 파일럿 α +0.5145%/월, p=0.3888은 별도의 비유의 연구 이력이며 VFS 성과가 아니다.
